# Mr Mobiles Website V2

Official static website for Mr Mobiles, Hosur.

## Live domain
https://mrmobiles.in

## Main customer flows
- Browse indicative product catalogue
- Confirm live stock and pricing through WhatsApp
- Repair enquiries
- Sell/exchange estimate and store quote
- Telegram Mini App launch
- Contact and map details

## Payment status
Razorpay online payment integration is intentionally pending. Do not add live payment keys to this repository.

## Brand
Use **Mr Mobiles** (not “MR MOBILES”).

## Deployment readiness
The repository is prepared for GitHub Pages with a custom domain file, sitemap, robots rules and a deployment workflow. GitHub Pages must be enabled once in repository settings before the first deployment. DNS for mrmobiles.in must then point to the chosen host.
